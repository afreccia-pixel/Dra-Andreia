# Dra. Andreia Medeiros — Ortodontia & Estética Dental

Website institucional de odontologia premium e ortodontia especializada da **Dra. Andreia Medeiros** (CRO-SC 8767) em Balneário Camboriú - SC.

---

## 🛠️ Tecnologias Utilizadas

- **React 18** — Interface reativa com componentes modulares
- **TypeScript** — Tipagem estática e segurança de código
- **Vite** — Build tool e bundler de alta performance
- **Tailwind CSS** — Estilização utilitária moderna e responsiva
- **Lucide React** — Biblioteca de ícones vetoriais leves
