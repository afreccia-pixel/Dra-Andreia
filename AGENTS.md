# Regras do Projeto

- **Gerenciamento de Imagens**:
  - Todas as imagens devem ser salvas e gerenciadas exclusivamente dentro da pasta `public/`.
  - Nunca coloque imagens dentro da pasta `src/`.
  - Nunca faça import de arquivos de imagem no topo dos componentes/arquivos.
  - Use sempre caminhos absolutos diretos baseados na raiz para renderizar imagens (ex: `<img src="/nome-da-imagem.webp" />`).

- **Layout e Estrutura de Conteúdo**:
  - Em páginas e artigos, a seção de **TAGS** deve ser posicionada **depois das Perguntas Frequentes (FAQ)**.
